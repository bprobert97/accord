## Reproducing the Paper Figures

The data-driven figures in the IEEE TAES paper (Figures 2-5) can be regenerated with a single script. Figure 1 is a flow chart and is not generated by code.

> Note: Generating all of the data required to reproduce all of the figures in this plot can take up to 3 days on a standard laptop. Generating Figure 4 is the fastest at around 12 hours.

### Steps

1. Complete the [Installation](README.md#installation) steps in README.md and activate your virtual environment.
2. From the repository root, run:
   * `python reproduce_figures.py`
3. Finished figures are copied to `paper_figures/`.

To generate only some of the figures:
* `python reproduce_figures.py --figures 4` (Figure 4 only; this is a single run and is much faster)
* `python reproduce_figures.py --figures 2 3`

The script runs headless (no plot windows open) and re-uses any simulation data already on disk, so re-running it only regenerates the plots. If a run is interrupted, re-run the same command and it resumes from the cached data. To force a fresh run of a configuration, delete its `mc_results_<ISL>km.npz` file (and the matching filter directory, e.g. `ekf_1000.0km/`).

### What is generated

| Figure | Content | Simulation settings | Plotting function | Output in `paper_figures/` |
|---|---|---|---|---|
| 2 | KPI comparison, 1000 km vs 2000 km ISL | `mc_demo.py`, EKF, random topology, 40 runs each | `plot_kpi_comparison` (`src/plotting/isl_mc_comparison.py`) | `figure2_isl_kpi_comparison.pdf/.png` |
| 3 | Reputation history, 1000 km vs 2000 km ISL | as Figure 2 | `plot_reputation_comparison` (`src/plotting/isl_mc_comparison.py`) | `figure3_isl_reputation_comparison.png` |
| 4 | Aggregated reputation, Walker-Delta | `accord_demo.py`, EKF, Walker-Delta, 600 km ISL, single run | `plot_aggregated_reputation` (`src/plotting/plotting.py`) | `figure4_walker_delta_reputation.png/.pdf` |
| 5 | KPI comparison, EKF vs CKF vs UKF | `mc_demo.py`, random topology, 1000 km ISL, 40 runs per filter | `plot_kpi_comparison` (`src/plotting/filter_mc_comparison.py`) | `figure5_filter_kpi_comparison.pdf/.png` |

The EKF / 1000 km Monte Carlo data is shared between Figures 2, 3 and 5, so only four Monte Carlo configurations are simulated in total (EKF 1000 km, EKF 2000 km, CKF 1000 km, UKF 1000 km).

### Running the steps manually

The script is equivalent to the following commands (ISL range is set with `--isl-range-km`):

```
python mc_demo.py --filter-type ekf --isl-range-km 1000 --no-plots
python mc_demo.py --filter-type ekf --isl-range-km 2000 --no-plots
python mc_demo.py --filter-type ckf --isl-range-km 1000 --no-plots
python mc_demo.py --filter-type ukf --isl-range-km 1000 --no-plots
python accord_demo.py --filter-type ekf --walker-delta True --isl-range-km 600
```

followed by the plotting functions listed in the table above.

### Notes

* **Runtime:** each Monte Carlo configuration is 40 runs of 400 satellites over 1000 steps, so a full reproduction takes a long time. Use `--figures 4` to check your setup quickly. Per-run logging is disabled by default for speed and does not affect results; pass `--logging` to keep it.
* **Cached data locations:** Monte Carlo filter data is stored per filter and ISL range (e.g. `ekf_1000.0km/`), and single-run results include the topology and ISL range in the filename (e.g. `sim_results_ekf_walker_600km.npz`), so different configurations never overwrite each other.
* **`--walker-delta`:** this flag uses `type=bool`, so any non-empty value (including `False`) is parsed as `True`. Omit the flag for a random topology.
* **Random seeds:** seeds are fixed in `DEFAULT_CONFIG` (`seed=42`, plus the run index), so results are deterministic for a given configuration.
